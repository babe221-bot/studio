# Stone Studio Configurator - Onboarding Guide

Welcome to the Stone Studio Configurator! This guide will help you get started quickly.

---

## Quick Start (5 Minutes)

### 1. Opening the App

Navigate to the configurator URL. You'll see:

- **Left Panel**: Configuration options (dimensions, materials, finishes)
- **Center**: 3D visualization of your stone slab
- **Right Panel**: Order items and actions

### 2. Creating Your First Configuration

1. **Select Element Type** - Choose from counter, table top, step, windowsill, or other
2. **Enter Dimensions** - Input length, width, and thickness in centimeters
3. **Choose Material** - Browse available stones by clicking the material selector
4. **Configure Edges** - Select finish type and edge profile
5. **Add to Order** - Click the button to add to your work order

### 3. Exporting

- **Download PDF** - Generates a work order with all items and totals
- **Save Template** - Store configuration for reuse
- **Share** - Generate a link to share with colleagues

## Voice Commands

Activate voice control by clicking the microphone button. Available commands:

| Command          | Action                      |
| ---------------- | --------------------------- |
| "Povećaj dužinu" | Increase length by 10cm     |
| "Smanji širinu"  | Decrease width by 10cm      |
| "Dodaj u nalog"  | Add current config to order |
| "Obriši sve"     | Clear all items             |

## Configuration Options

### Element Types

- **Radna ploča** (Counter) - Kitchen counters
- **Stolna ploča** (Table) - Table tops
- **Stepenik** (Step) - Stair steps
- **Prozorski daske** (Windowsill) - Window sills
- **Vanjski rub** (Outer edge) - Exterior edges

### Materials

Browse the material selector for available stone types. Each material shows:

- Name and origin
- Price per square meter
- Preview image

### Edge Finishes

- **Oštre** (Sharp) - Straight cut edges
- **Lomljene** (Broken) - Chiseled/rustic edges

### Surface Finishes

- **Polirano** - Polished
- **Brušeno** - Honed
- **Flamed** - Thermal treated

## Troubleshooting

### 3D View Not Loading

- Ensure WebGL is enabled in your browser
- Try refreshing the page
- Check browser console for errors

### Voice Commands Not Working

- Allow microphone permissions
- Speak clearly in Serbian
- Check browser compatibility

### PDF Download Fails

- Ensure pop-ups are allowed
- Try a different browser
- Check internet connection
