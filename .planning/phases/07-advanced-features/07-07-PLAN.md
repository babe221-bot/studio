# Plan 07-07: Analytics Dashboard

## Objective

Implement comprehensive analytics tracking and dashboards for understanding user behavior, revenue, and product performance.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + PostHog (existing) + Recharts (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-07-analytics-dashboard.md`

## Scope

### In Scope

1. PostHog event tracking implementation
2. Custom event taxonomy
3. Analytics API endpoints
4. Dashboard UI with charts
5. Revenue analytics
6. Material popularity tracking

### Out of Scope

- Advanced cohort analysis
- Custom report builder
- Real-time dashboard (hourly refresh sufficient)

## Tasks

### Task 1: Event Tracking Implementation

**Type:** `auto`
**Description:** Implement comprehensive PostHog tracking

**Implementation:**

- Add tracking to Lab component:
  - session_start, session_end
  - material_selected, material_viewed
  - dimension_changed, finish_changed
  - configuration_saved, configuration_loaded
  - export_started, export_completed
  - checkout_started, checkout_completed
- Add tracking to backend (pricing, orders)
- Set up user identification

**Verification:**

- Events appear in PostHog
- Event properties are correct
- User journey is trackable

**Files:**

- `src/lib/analytics.ts` - NEW (tracking wrapper)
- `src/components/Lab.tsx` - Modify
- `src/hooks/useAnalytics.ts` - NEW
