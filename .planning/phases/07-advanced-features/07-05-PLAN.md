# Plan 07-05: Extended Material Library

## Objective

Expand the material library with comprehensive stone types, categories, custom textures, and user management features.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + Three.js + Supabase (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-05-material-library.md`

## Scope

### In Scope

1. Extended stone type taxonomy (marble, granite, quartz, etc.)
2. Material categories and organization
3. Search and filtering
4. Custom texture upload (normal, roughness maps)
5. Material pricing integration
6. User favorites/presets
7. Material preview generation

### Out of Scope

- KTX2/Basis texture compression (future optimization)
- Material blending/mixing
- Multi-language support

## Key Decisions

1. **Supabase Storage** - Already integrated, use for texture storage
2. **Client-side preview** - Three.js renders materials, no server needed
3. **Soft delete** - Keep material history for orders
4. **Tiered pricing** - Category-based pricing multipliers
