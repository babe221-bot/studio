# Plan 07-05: Cross-section View and Measurement Tools

## Objective

Add cross-section slicing capability and interactive measurement tools (distance, angle, area) to the 3D VisualizationCanvas for enhanced design inspection and validation.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + Three.js + React Three Fiber + Supabase (existing)
- **Dependencies**: Builds upon existing VisualizationCanvas and Lab component

## Scope

### In Scope

1. Cross-section plane controls (position, orientation, toggle)
2. Interactive measurement tools:
   - Distance tool (point-to-point)
   - Angle tool (three-point angle)
   - Area tool (polygon area calculation)
3. Measurement persistence and snapping to geometry
4. Visualization of measurement results in UI
5. Integration with existing dimension labels and visualization controls

### Out of Scope

- Advanced solid boolean operations (requires CSG libraries)
- 3D measurement along curved surfaces
- Measurement export to PDF/CAD
- Collaborative measurement sharing

## Tasks

### Task 1: Cross-section Plane Implementation

**Type:** `auto`
**Description:** Add cross-section slicing plane controls to VisualizationCanvas with clipping plane support

**Implementation:**

- Add clipping plane support to Three.js scene in VisualizationCanvas
- Create CrossSectionControls UI component for plane position/rotation
- Add toggle to enable/disable cross-section view
- Update StoneSlabMesh to respect clipping planes
- Add plane visualization helper (optional, for debugging)
- Store cross-section state in CadContext or use Zustand store
