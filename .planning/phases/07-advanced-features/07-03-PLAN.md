# Plan 07-03: Email Notifications

## Objective

Implement transactional email notifications for user actions (welcome, order confirmations, receipts) using Resend.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + FastAPI + Resend (to add)
- **Research**: `.planning/phases/07-advanced-features/research/07-03-email-notifications.md`

## Scope

### In Scope

1. Resend setup and configuration
2. Email template system (React Email)
3. Welcome email for new registrations
4. Order confirmation emails
5. Payment receipt emails
6. User preferences for email types

### Out of Scope

- Marketing email campaigns
- SMS notifications
- Push notifications (covered in PWA plan)

### Task 5: Async Email Queue (Optional Enhancement)

**Type:** `checkpoint:decision`
**Description:** Implement background email processing

**Decision:** Skip for now - sync sending is sufficient for MVP. Can add Redis/Celery later if volume increases.

**Current Approach:** Direct Resend API calls (simpler, sufficient for <100 emails/day)

## Success Criteria

- [ ] Resend API integration works
- [ ] Welcome emails send on registration
- [ ] Order confirmations send on checkout
- [ ] Receipts send on payment
- [ ] User preferences save/load correctly
- [ ] Emails render correctly in inbox
- [ ] TypeScript compiles without errors

## Key Decisions

1. **Resend** - Best developer experience, competitive pricing, excellent Next.js integration
2. **React Email** - Type-safe templates, easy to customize
3. **Sync sending** - Sufficient for current volume, queue deferred
