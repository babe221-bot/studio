# Plan 07-06: PWA Enhancements

## Objective

Transform the application into a full Progressive Web App with offline support, push notifications, and installability.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + Service Workers (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-06-pwa-enhancements.md`

## Scope

### In Scope

1. PWA manifest configuration
2. Service worker with Workbox
3. Offline mode for configurator
4. Push notifications (web push)
5. Background sync for saved configs
6. Install prompt handling

### Out of Scope

- iOS APNs (requires Apple Developer)
- Complex offline workflows
- Background processing

## Key Decisions

1. **Workbox** - Stable, well-documented, Next.js compatible
2. **IndexedDB** - For offline config storage, cross-browser support
3. **Web Push** - Standard protocol, no vendor lock-in
4. **Custom install UI** - Better UX than browser default
