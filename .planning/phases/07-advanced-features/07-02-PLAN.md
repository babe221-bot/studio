# Plan 07-02: Admin Dashboard

## Objective

Build a comprehensive admin dashboard for managing users, orders, materials, and viewing analytics with role-based access control.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + FastAPI + SQLite + shadcn/ui (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-02-admin-dashboard.md`

## Scope

### In Scope

1. Admin route structure with protected layouts
2. User management (CRUD, roles, status)
3. Order management (status, fulfillment, assignment)
4. Material management (CRUD, inventory)
5. Analytics dashboard with charts
6. Audit logging for admin actions

### Out of Scope

- Multi-tenant organization management
- Advanced reporting/exports
- Workflow automation

## Tasks

**Type:** `auto`
**Description:** Extend database with roles and audit logging

**Implementation:**

- Add `role` field to UserProfileDB (customer/staff/manager/admin/superadmin)

- Add order fulfillment fields (fulfillment_status, assigned_staff_id, tracking)
- Add material inventory fields (inventory_count, low_stock_threshold, sku, supplier)

**Verification:**
