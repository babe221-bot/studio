# Plan 07-01: Real-Time Collaboration Infrastructure

## Objective

Implement real-time collaboration infrastructure enabling multiple users to simultaneously edit stone slab configurations with presence indicators and conflict resolution.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + FastAPI + Supabase (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-01-collaboration.md`

## Scope

### In Scope

1. Supabase Realtime channel setup for configuration sync
2. Delta-based state synchronization
3. Presence indicators (who's online)
4. Timestamp-based conflict resolution
5. Guest session collaboration support

### Out of Scope

- CRDT-based offline sync (defer to future)
- Complex field-level locking for CAD export
- Mobile-optimized collaboration UI

## Architecture

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Next.js       │────▶│   Supabase       │────▶│   FastAPI       │
│   Frontend      │     │   Realtime       │     │   Backend       │
│   (R3F + Zustand)     │   (Broadcast +   │     │   (CAD Service) │
│                 │◀────│   Presence)      │◀────│                 │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

- [ ] Changes sync within 200ms
- [ ] Presence shows online users with avatars

- [ ] Conflicts resolve without data loss
- [ ] Guest sessions can collaborate
- [ ] TypeScript compiles without errors
- [ ] ESLint passes

## Key Decisions

1. **Supabase Realtime** - Leverages existing Supabase integration, minimal new infrastructure
2. **Last-Write-Wins** - Sufficient for configurator; CRDT deferred for complexity
3. **Delta Updates** - 80-90% bandwidth reduction vs full state sync
4. **150ms Throttling** - Balances responsiveness with network efficiency
