# Plan 07-04: Advanced CAD Export

## Objective

Implement advanced CAD export formats (STL, OBJ, GLTF) for stone slab configurations, enabling manufacturing and CAD software compatibility.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + Three.js + FastAPI + Blender (existing)
- **Research**: `.planning/phases/07-advanced-features/research/07-04-advanced-export.md`

## Scope

### In Scope

1. STL binary export (primary for manufacturing)
2. OBJ export (CAD compatibility)
3. GLTF/GLB export (web/AR)
4. Mesh simplification for reduced file sizes
5. Export quality presets
6. Multi-slab export

### Out of Scope

- FBX/STEP formats (require Blender server-side)
- Texture embedding in OBJ
- Advanced mesh processing

## Architecture

```
Client-Side (Three.js):
  - STLExporter, OBJExporter, GLTFExporter
  - Mesh simplification via SimplifyModifier

Server-Side (Blender - existing):
  - Advanced format support (future)
  - Batch processing (future)
```

## Key Decisions

1. **Client-side export** - Three.js has native exporters, no extra dependencies
2. **STL binary** - Smaller than ASCII, preferred by manufacturers
3. **Quality presets** - Balance file size vs visual fidelity
4. **ZIP for multi-slab** - Clean packaging, easy handling
