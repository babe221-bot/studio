# Plan 07-04: Material Library Browser and Real-time Physics Simulation

## Objective

Add a visual material library with textures and properties that users can browse and apply to their designs, and implement basic physics for material behavior in the 3D view.

## Context

- **Project**: Stone slab 3D configurator
- **Stack**: Next.js 16 + Three.js + React Three Fiber + Supabase (existing)
- **Dependencies**: Builds upon existing material system and VisualizationCanvas

## Scope

### In Scope

1. Material Library Browser:
   - Visual grid/material cards with texture previews
   - Search and filtering by stone type, color, price, etc.
   - Detailed material view with PBR properties
   - Custom texture upload (normal, roughness, displacement maps)
   - Material favorites and user presets

2. Real-time Physics Simulation:
   - Basic physics for material behavior (flexibility, weight distribution)
   - Physics visualization in 3D view (bending, sagging simulation)
   - Material property integration (density, elasticity)
   - Interactive physics parameters (thickness, support points)

### Out of Scope

- Advanced physics engines (Cannon.js, Ammo.js) - use simplified simulation
- Complex fluid dynamics or fracture simulation
- Real-time stress/strain analysis with FEM
- Physics-based material optimization
